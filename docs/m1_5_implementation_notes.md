# M1.5 正式体验骨架 · 实现记录

> 2026-08-24：M1.5 骨架之上已增加 M2 内容结构首版。下面保留原始实现记录；新增结构见文末“内容结构扩展”。

## 本轮完成

### 1. 世界层

- 路由：`/`
- 使用 `world-atlas/land-110m`（Natural Earth）生成真实海陆轮廓；
- 不绘制现代国界；
- 罗马是唯一开放文明，其余暗节点均来自真实内容计划；
- 文明位置由 `src/content/world/*.yaml` 的真实经纬度驱动。

### 2. 罗马卷

- 路由：`/world/rome-republic/`
- 使用独立暖色、石质、对称构图，与冷色世界层区分；
- 人物与制度进入关系构图，不被钉在地图坐标上；
- 地中海地图只作为空间参照；
- 卢比孔以故事入口而非文章卡片呈现；
- 四个未开放故事来自真实规划内容。

### 3. 卢比孔故事

- 路由：`/story/rubicon/`
- 三幕通过纵向滚动与进度导航切换：
  1. 真实地中海空间与军权范围；
  2. imperium 四条轨道与政治程序；
  3. 卢比孔位置争议与证据精度耗尽。
- 内容从 `src/content/scenes/rubicon.yaml` 读取；
- 核心论断可打开证据抽屉；
- 人物、地点、制度和文献可打开对象抽屉。

### 4. 对象页

- 路由：`/entity/:id/`
- 为所有已开放对象静态生成页面；
- 地点使用真实意大利地图，人物 / 制度 / 文献使用非地理构图；
- 每个对象展示至少三条继续路径，并可返回故事或罗马卷。

### 5. 地理修复

修正了 `src/lib/geo.ts` 中用于 D3 `fitExtent` 的球面多边形外环方向。外环反向时，D3 会把框外的整个球面识别为拟合对象，导致“地中海取景”退化为世界尺度。世界与区域投影现统一使用顺时针外环。

## 验证

- `npm run build`：通过，生成 12 个静态页面；
- `npx astro sync && npx tsc --noEmit`：通过；
- 浏览器无 console error；
- 已跑通：

  `世界 → 罗马卷 → 卢比孔 → 三幕推进 → 对象抽屉 → 证据抽屉 → 对象页 → 返回`

## 已知限制

1. 核心法律论断的现代研究引注仍按内容数据明确标记为 M3 待补；
2. `@astrojs/check@0.9.10` 尚未声明兼容项目现用的 TypeScript 7，因此未使用 `--force` 安装；
3. 当前视觉审核以桌面端为主，移动端已有响应式布局但仍需真机 / 窄视口专项调整；
4. 独立概念示范 `public/prototypes/codex-world-demo.html` 继续保留，仅作方向档案。

## 内容结构扩展（M2 首版）

### 1. 文明时间主干

- 新路由：`/civilization/rome/`；
- 世界层的罗马入口先到文明主干，不再直接跳入共和国危机；
- 当前编辑范围约前 753—公元 476 年，拆为九个语义时代卷；
- 时代长度由结构变化决定，不强行按世纪等分；
- 只有“共和国危机”作为实验样卷开放，其余时代诚实标注为规划中；
- 公元 476 年明确为西部编辑范围终点，不冒充罗马历史终点。

### 2. 卢比孔知识章节

- 三幕视觉舞台保留，不再等同于三段内容；
- `src/content/chapters/rubicon.yaml` 提供八段读者叙事：问题、背景、机制、程序、行动、后果、后世记忆、总结；
- `src/content/scenes/rubicon.yaml` 继续负责视觉配置与可核查论断；
- 章节段落通过 `claimRefs` 打开证据，通过 `entities` 打开对象关系；
- 增加凯撒当事人叙述、二世纪后世传统和现代研究三个史料层次。

### 3. 新的发现路径

`历史世界 → 罗马时间主干 → 共和国危机时代卷 → 卢比孔知识章节 → 对象 / 论断 / 来源`

详细设计见 `docs/m2_content_architecture.md`。
