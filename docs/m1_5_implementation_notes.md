# M1.5 正式体验骨架 · 实现记录

## 本轮完成

### 1. 世界层

- 路由：`/`
- 使用 `world-atlas/land-110m`（Natural Earth）生成真实海陆轮廓；
- 不绘制现代国界；
- 罗马是唯一开放文明，其余暗节点均来自真实内容计划；
- 文明位置由 `src/content/world/*.yaml` 的真实经纬度驱动。

### 2. 罗马卷

- 路由：`/world/rome-republic/`
- 使用独立暖色、石质、对称构图，与冷色世界层区分；
- 人物与制度进入关系构图，不被钉在地图坐标上；
- 地中海地图只作为空间参照；
- 卢比孔以故事入口而非文章卡片呈现；
- 四个未开放故事来自真实规划内容。

### 3. 卢比孔故事

- 路由：`/story/rubicon/`
- 三幕通过纵向滚动与进度导航切换：
  1. 真实地中海空间与军权范围；
  2. imperium 四条轨道与政治程序；
  3. 卢比孔位置争议与证据精度耗尽。
- 内容从 `src/content/scenes/rubicon.yaml` 读取；
- 核心论断可打开证据抽屉；
- 人物、地点、制度和文献可打开对象抽屉。

### 4. 对象页

- 路由：`/entity/:id/`
- 为所有已开放对象静态生成页面；
- 地点使用真实意大利地图，人物 / 制度 / 文献使用非地理构图；
- 每个对象展示至少三条继续路径，并可返回故事或罗马卷。

### 5. 地理修复

修正了 `src/lib/geo.ts` 中用于 D3 `fitExtent` 的球面多边形外环方向。外环反向时，D3 会把框外的整个球面识别为拟合对象，导致“地中海取景”退化为世界尺度。世界与区域投影现统一使用顺时针外环。

## 验证

- `npx astro sync && npx tsc --noEmit`：通过；

- 已跑通：

  `世界 → 罗马卷 → 卢比孔 → 三幕推进 → 对象抽屉 → 证据抽屉 → 对象页 → 返回`
